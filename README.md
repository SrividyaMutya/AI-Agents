# AI-Agents

A 12-Day AI Agents Workshop Journey at Aditya University.

Exploring Agentic AI, LLMs, Python, APIs, LangChain, LangGraph, RAG, and intelligent AI agent development through hands-on learning and practical projects.

## Workshop Duration
23 November – 5 December 2026

## Learning Journey
- Day 1: First API Call and LLM Basics
- Day 2: Prompts, JSON and Python
- Day 3: First AI Agent
- Day 4: Tools and Pydantic
- Day 5: Memory and RAG
- Day 6: LangGraph
- Day 7–12: Advanced AI Agents and Capstone
